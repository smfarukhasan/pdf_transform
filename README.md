# KhubSojaDoc (খুব সোজা ডক) - PDF Transform & Office Suite

A powerful, all-in-one Android PDF and Document Editor application built with Flutter.

## Features (বৈশিষ্ট্যসমূহ)
- **PDF Page Editor:** Delete pages, add blank pages, add image pages, rotate, reorder, merge PDFs.
- **PDF Converter:**
  - PDF to Image: Batch conversion with custom page marking, range selection, and crystal clear opaque white background.
  - PDF to Text / Word (DOCX).
- **Draft System:** Automatic draft saving and resume capability.
- **Office Suite:** View and edit Word (DOCX), Excel (XLSX), and PowerPoint (PPTX).
- **Image Tools:** Crop, resize, compress to target KB or quality without black artifacts.
- **Document Scanner:** Multi-page camera/gallery scanner with Document B&W, Grayscale, and Color filters.
- **Document Reader:** High-resolution zoom, rotate, bookmarks, direct editing, text extraction.
- **Dedicated Folder:** Dedicated `KhubSojaDoc` folder for clean organization.
- **Android Support:** Optimized for Android 12+ (minSdk 31).

## Getting Started
```bash
flutter pub get
flutter run
```

## Build Release APK
```bash
flutter build apk --release
```
